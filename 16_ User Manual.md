
# User Manual

# KleanFlow Laundry Pickup & Delivery Management System

---

# 1. Introduction

KleanFlow helps laundry businesses manage:

- Customers
- Orders
- Payments
- Receipts
- Pickups
- Deliveries

---

# 2. Login

Steps:

1. Open application.
2. Enter email.
3. Enter password.
4. Click Login.

---

# 3. Dashboard

The dashboard displays:

- Total customers
- Orders
- Revenue
- Pending tasks
- Recent activities

---

# 4. Creating a Customer

Steps:

1. Open Customers.
2. Click Add Customer.
3. Enter customer information.
4. Save.

---

# 5. Creating Laundry Order

Steps:

1. Select customer.
2. Select services.
3. Add clothing details.
4. Calculate total.
5. Save order.

---

# 6. Recording Payment

Steps:

1. Open order.
2. Click Payment.
3. Enter amount.
4. Select method.
5. Save.

---

# 7. Printing Receipt

Steps:

1. Open completed payment.
2. Select Receipt.
3. Click Print.

---

# 8. Managing Laundry Status

Order statuses:

```
Pending

Washing

Ironing

Ready

Completed
```

---

# 9. Delivery Management

Steps:

1. Open Delivery.
2. Assign staff.
3. Update delivery status.

---

# 10. Reports

Managers can view:

- Sales
- Revenue
- Customers
- Payments
